# **App Name**: Potoba

## Core Features:

- Firebase Authentication: User authentication using Firebase Auth. Handles user sign-up, sign-in, and sign-out.
- Role Management: Role-based access control to restrict dashboard based on user role.
- Role-Based Dashboard: Dashboard displays user-specific data based on role.
- Route Protection: Route protection to redirect authenticated users to the dashboard and prevent access to the login page if already logged in.

## Style Guidelines:

- Primary color: Orange (#FFB347) for trustworthiness.
- Secondary color: Light Gray (#ecf0f1) for backgrounds and subtle accents.
- Accent: Teal (#1abc9c) for interactive elements and call-to-actions.
- Clean, sans-serif typography for readability and a modern feel, using fonts suitable for large displays.
- Simple, intuitive dashboard layout with clear navigation, inspired by modern, large-format web designs. Uses the shadcn component library.
- Use simple, line-based icons for navigation and key features, with a focus on food-related icons.
- Subtle, engaging animations throughout the UI to enhance user experience. Incorporates food-themed transitions and effects.
